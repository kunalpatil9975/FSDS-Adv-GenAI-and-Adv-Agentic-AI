# AI/ML Industry Requirements

## Install everything
```bash
pip install -r requirements.txt
```

## Install by domain
```bash
pip install -r requirements/requirements-ml.txt
pip install -r requirements/requirements-dl.txt
pip install -r requirements/requirements-cv.txt
pip install -r requirements/requirements-genai.txt
pip install -r requirements/requirements-mlops.txt
```

## Recommended
Use a Python virtual environment before installation:
```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```
